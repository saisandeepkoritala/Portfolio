# My Portfolio Website

Welcome to the repository for my personal portfolio website. This platform showcases my professional journey, skills, projects, and experience as a software developer. It is built using React, powered by Vite for an ultra-fast development experience, and styled for a modern, responsive user experience.

## 🚀 Live Demo

Check out the live site here: **[saisandeepkoritala-portfolio.netlify.app](https://saisandeepkoritala-portfolio.netlify.app/)**

---

## 🛠️ Tech Stack & Utilities

* **Frontend Tooling:** Vite
* **Frontend Framework:** React
* **Language:** JavaScript
* **Styling & UI Components:** CSS
* **Icons:** React Icons
* **Deployment:** Netlify

---

## ✨ Features

* **Blazing Fast Build:** Powered by Vite's HMR (Hot Module Replacement) and Esbuild.
* **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.
* **Dark Mode Support:** Smooth toggling between light and dark themes.
* **Project Showcase:** A curated list of my top projects featuring descriptions, tech tags, and source code links.
* **Interactive Experience Components:** A clean timeline detailing my professional employment and open-source contributions.
* **Contact Form:** A streamlined way for recruiters and collaborators to get in touch.
